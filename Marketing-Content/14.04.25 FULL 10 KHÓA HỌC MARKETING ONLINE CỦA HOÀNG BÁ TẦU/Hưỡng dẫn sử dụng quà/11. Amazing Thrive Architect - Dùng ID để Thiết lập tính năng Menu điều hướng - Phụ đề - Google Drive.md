# 11. Amazing Thrive Architect - Dùng ID để Thiết lập tính năng Menu điều hướng - Phụ đề - Google Drive

## 💡 Tóm Tắt Cốt Lõi
- Cách gán mã CSS ID cho phần tử trong Thrive Architect để tạo điểm tham chiếu cho menu điều hướng.
- Tạo Custom Link trong WordPress Menu bằng định dạng `#ID` để kích hoạt điều hướng khi click.
- Kiểm tra kết quả bằng cáchấn F5 sau khi chỉnh sửa để xác nhận smooth scroll/cuộn đến phần tử.

## 📖 Nội Dung Chi Tiết

### 1. Thiết lập CSS ID cho phần tử trong Thrive Architect
- Chọn phần tử cần điều hướng trên trang.
- Truy cập tab **Advanced** trong settings của phần tử.
- Nhập mã ID mong muốn vào ô **CSS ID** (ví dụ: `123`). ID nên dùng ký tự chữ số và chữ cái, tránh khoảng trắng để đảm bảo tính duy nhất.
- Mã ID này sẽ đóng vai trò là điểm tham chiếu (anchor) cho menu điều hướng.

### 2. Tạo menu điều hướng liên kết đến phần tử đó
- Vào **Appearance > Menu** trong bảng điều khiển WordPress.
- Tạo menu mới, chọn mục **Custom Link**.
- Điền URL theo định dạng `#ID` (ví dụ: `#123`).
- Lưu menu và gán vào vị trí hiển thị mong muốn (Header, Footer, v.v.).
- Ấn **F5** để tải lại trang và kiểm tra: khi click vào mục menu, trình duyệt sẽ tự động cuộn đến phần tử có ID tương ứng.

> **Ví dụ/Case Study:** Giả sử bạn muốn nút "Giới thiệu tác giả" ở cuối bài viết khi click vào mục menu "Author Intro", sẽ nhảy đến đoạn văn bản có CSS ID là `author-intro`.

### 3. Lưu ý kỹ thuật
- ID phải duy nhất trên toàn bộ trang web; không nên trùng lặp giữa các phần tử.
- Tránh sử dụng ký tự đặc biệt hoặc khoảng trắng trong ID; ưu tiên dùng tên mô tả như `header`, `about-us`, `contact`...
- Phương pháp này áp dụng không chỉ Thrive Architect mà cũng cho WordPress Block Editor thông qua tùy chọn CSS Class/ID tùy theme.

## ❓ Câu Hỏi & Trả Lời Trọng Tâm (Q&A for Search)
- **Hỏi:** Cách thiết lập menu điều hướng nhảy đến phần tử cụ thể bằng ID trong Thrive Architect là như thế nào?
  - **Đáp:** Chọn phần tử → Tab Advanced → CSS ID → nhập mã ID → Tạo Custom Link trong WordPress Menu với URL `#mã_ID` → Lưu và F5 kiểm tra. Click menu sẽ cuộn đến phần tử có ID khớp.
- **Hỏi:** Định dạng URL để điều hướng đến phần tử có ID là gì?
  - **Đáp:** Cú định dạng là `#ID` (ví dụ: `#123` hoặc `#author-intro`). Đặt vào ô URL khi tạo Custom Link trong menu WordPress.
- **Hỏi:** Làm sao để đảm bảo menu điều hướng hoạt động đúng trên Thrive Architect sau khi chỉnh sửa?
  - **Đáp:** ID phải khớp chính xác với ID gán cho phần tử. Sau khi sửa xong,ấn F5 để tải lại trang, hệ thống sẽ nhận diện thay đổi và menu sẽ nhảy đúng phần tử mục tiêu.
