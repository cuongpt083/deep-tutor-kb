# 8. Hướng Dẫn Cài Đặt và Kích hoạt Plugin - Phụ đề - Google Drive

## 💡 Tóm Tắt Cốt Lõi
- Hướng dẫn cài đặt và kích hoạt plugin WordPress cho công cụ EditTri-Content Builder.
- Quy trình di chuyển đến gói mở rộng, chọn file, cài đặt và active.
- Cách cấu hình tab Visual, chọn mục Lê Sơn Manager và nhập license key để kích hoạt tính năng.
- Sử dụng plugin để thiết kế landing page và đặt ngôn ngữ cho website.

## 📖 Nội Dung Chi Tiết
### 1. Cài đặt và Kích hoạt Plugin trên WordPress
- Truy cập tài khoản WordPress và vào phần **Gói mở rộng (Extensions)**.
- Chọn **Cài đặt mới (Add New)** hoặc bấm upload file plugin.
- Chọn file tài liệu/plugin đã tải về, bấm **Open** và sau đó **Install**.
- Sau khi cài xong, vào mục **Đã cài đặt** và bấm **Active** để kích hoạt plugin.

### 2. Cấu hình tab Visual và chọn mục chức năng
- Di chuyển xuống tab **Visual**.
- Tìm mục **Lê Sơn Manager** (hoặc mục tương ứng) và bấm nút **Active** để kích hoạt.
- Nếu chưa active, hệ thống sẽ hiển thị trạng thái "Chưa kích hoạt", bấm Active để chuyển sang trạng thái hoạt động.

### 3. Nhập thông tin license và kích hoạt tính năng
- Trong mục cấu hình, nhập **Email** và **License key** (nhận được từ tài khoản học viên/course provider).
- Bấm **Action Active** để hoàn tất quá trình kích hoạt.
- Sau khi kích hoạt, plugin sẽ chạy trên website và cho phép thiết kế các trang Landing page và cấu hình ngôn ngữ cho Website.

> **Ví dụ / Case Study:** Giảng viên演示 (demo) toàn bộ quy trình: từ bước vào WordPress → Gói mở rộng → Chọn file plugin → Install và Active → Tab Visual → Mục Lê Sơn Manager → nhập Email và License key → Kích hoạt → Trang web chạy và hỗ trợ thiết kế Landing page cùng đặt ngôn ngữ cho Website. Đây là quy trình thực tế để triển khai hệ thống đầu phễu trên WordPress.

## ❓ Câu Hỏi & Trả Lời Trọng Tâm (Q&A for Search)
- **Hỏi:** Cách cài đặt và kích hoạt plugin EditTri-Content Builder trên WordPress như thế nào?
  - **Đáp:** Truy cập phần Gói mở rộng, chọn file plugin, bấm Install và Active. Sau đó vào tab Visual, chọn mục Lê Sơn Manager và nhập Email cùng License key để kích hoạt chức năng.
- **Hỏi:** Các bước cần làm sau khi cài đặt plugin xong để bắt đầu thiết kế Landing page?
  - **Đáp:** Cuộn xuống tab Visual, bấm Active vào mục Lê Sơn Manager, nhập thông tin license key và Email nhận được, sau đó plugin sẽ hoạt động và hỗ trợ thiết kế Landing page cùng đặt ngôn ngữ cho Website.
- **Hỏi:** License key và Email nhập ở bước nào và từ đâu lấy?
  - **Đáp:** Nhập tại mục cấu hình sau khi bấm Active vào Lê Sơn Manager; License key và Email được cung cấp từ tài khoản khóa học/course provider (Hoàng Bá Tàu / SuccessOcean).
