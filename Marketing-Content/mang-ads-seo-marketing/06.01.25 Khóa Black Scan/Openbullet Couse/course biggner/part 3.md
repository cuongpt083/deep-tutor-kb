# Openbullet/Openbelt Cracking Configuration & Proxy Setup (Part 3)

## 💡 Tóm Tắt Cốt Lõi
- Hướng dẫn đăng ký và获取 config/checker cho các trang mục tiêu.
- Phân loại và sử dụng proxy (kèm yêu cầu proxy riêng tư cho Netflix).
- Tổng quan công cụ Openbullet/Openbelt và các phiên bản (Openbelt, Loli, Lolx, Black Belt 2.6.1).
- Quy trình quét file config và tạo word list cho cracking.

## 📖 Nội Dung Chi Tiết
### 1. Đăng ký & Tìm config/Checker
- Bạn cần đăng ký tài khoản trên site mục tiêu để lấy config hoặc checker dùng cho cracking.
- Quá trình tìm config đòi hỏi thực hiện search với từ khóa "null" hoặc "cracking 2".
- Mỗi combo cập nhật mỗi 1 phút, bao gồm proxy mới; cần tìm proxy chất lượng để cấu hình công cụ.

### 2. Cấu hình Proxy & Lưu ý Netflix
- Proxy là yếu tố then chốt; cho Netflix cần sử dụng proxy riêng tư (private proxy).
- Ví dụ proxy HQ có thể dùng để test kết nối.
- Cấu hình config Netflix: đã có config hoạt động nhưng bắt buộc cần proxy riêng tư để chạy thành công.

### 3. Công cụ Openbullet/Openbelt
- Openbelt là công cụ cracking nổi tiếng, dễ sử dụng và nhanh.
- Có nhiều phiên bản: Openbelt (chuẩn), Loli, Lolx. Phiên bản Openbelt không bao gồm nội dung Loli.
- Phiên bản Black Belt 2.6.1 là bản cập nhật mới, mang lại các tính năng và config bổ sung (ví dụ: config Openbvp).
- Người dùng có thể test nhiều phiên bản khác nhau để tìm phiên bản phù hợp với nhu cầu cracking.

### 4. Quét file & Tạo word list
- Sau khi có config, cần quét file để tìm config phù hợp.
- Tạo word list là bước quan trọng để cung cấp dữ liệu đầu vào cho công cụ cracking.
- Bài giảng sẽ hướng dẫn cách tạo word list theo đúng quy trình cần thiết.

> **Ví dụ/Case Study:** Test proxy cho Netflix, quét config cho Godaddy, thử các phiên bản Openbelt/Loli/Lolx để xác định khả năng gửi request.

### 5. Quy trình test & Triển khai
- Kiểm tra proxy trước khi cấu hình.
- Copy config vào file, chạy scan config.
- Thử nghiệm từng phiên bản (ví dụ: Openbelt vs Loli vs Lolx) và khả năng gửi request.
- Kết quả: Phiên bản Openbelt hiện tại ổn định cho các target không yêu cầu nội dung Loli.

## ❓ Câu Hỏi & Trả Lời Trọng Tâm (Q&A for Search)
- **Hỏi:** Cần đăng ký trước khi dùng công cụ cracking không?
- **Đáp:** Có, đăng ký là bước bắt buộc để lấy config và checker cho site bạn muốn cracking.
- **Hỏi:** Proxy loại nào cần dùng cho Netflix?
- **Đáp:** Cần dùng proxy riêng tư (private proxy), proxy công cộng thường không đáp ứng yêu cầu của config Netflix.
- **Hỏi:** Phiên bản Openbelt và Loli có khác nhau không?
- **Đáp:** Có, phiên bản Openbelt hiện tại không bao gồm tính năng Loli; có các phiên bản khác có Loli và Lolx tùy theo nhu cầu.
- **Hỏi:** Cách tạo word list như thế nào?
- **Đáp:** Bài giảng hướng dẫn tạo word list và quét file config; word list đóng vai trò là dữ liệu đầu vào cho quá trình cracking.
